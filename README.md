# 🛒 TechSpear - E-commerce Frontend

**TechSpear** is a full-stack e-commerce web application designed for selling **laptops, PCs**, and offering related **technical services**. This repository contains the **frontend** source code built with **React**, styled using **Tailwind CSS**, and integrated with the backend via RESTful APIs.

---

## 🔥 Live Demo
[Visit the live site](https://techspear-ecom.vercel.app)
---

## ✨ Features

- 🔍 Browse laptops, desktops, and accessories with filter & search options
- 🛒 Add to cart, manage quantities, and smooth checkout
- 💳 Secure online payment integration
- 📦 Track orders and view purchase history
- 🧾 **Email Notifications** for order confirmation, service updates, and promotions
- 🧾 **Invoice Generation** downloadable in PDF format after each order
- 🛠️ Book service appointments (repairs, upgrades)
- 👤 User authentication & profile management
- 🌙 Dark mode support
- 📱 Mobile responsive design

---

## ⚙️ Tech Stack

### Frontend:
- **React**
- **Redux Toolkit**
- **React Router**
- **Tailwind CSS**
- **Axios**
- **Vercel** (for deployment)
